# Send Money Home — Compare

Compare money-transfer services for sending money from Canada abroad. Enter an amount in CAD, pick the destination currency, and see which provider puts the most money in your recipient's hands.

- Live mid-market rates (free API, cached offline)
- Editable provider profiles: flat fee, % fee, rate margin, speed
- Ranked results with "best deal" savings vs the worst option
- Share comparisons via WhatsApp / native share
- No account, no server — all data stays on your device

Built with plain HTML/CSS/JS. Published as a web app and Android APK.
